# 🗣️ Voice Vocabulary Learning Agent

A smart, interactive voice-based AI agent that helps people learn and master new vocabulary words through gamified learning and real-time feedback.

## 🎯 Features

- **Multi-Level Learning**: Beginner, Intermediate, and Advanced difficulty levels
- **Interactive Quiz Mode**: Learn words and test your knowledge immediately
- **Scoring System**: Track your progress with points and streak counter
- **Hint System**: Get helpful hints when you're stuck
- **Beautiful UI**: Clean, intuitive interface built with Gradio
- **Instant Feedback**: Immediate responses to your answers
- **Voice-Ready**: Built with speech recognition pipeline ready for integration

## 🚀 How to Use

### Option 1: Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/RiyaAddanki/voice-vocabulary-agent.git
   cd voice-vocabulary-agent
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash
   python app.py
   ```

4. **Open in browser**
   - The app will automatically open at `http://localhost:7860`
   - Or visit the share link printed in the terminal

### Option 2: Deploy on Hugging Face Spaces (Free!)

1. Go to [Hugging Face Spaces](https://huggingface.co/spaces)
2. Create a new Space with Gradio
3. Upload the files from this repo
4. The app will deploy automatically
5. Share the public link with others!

## 📚 Learning Flow

1. **Select Difficulty Level** - Choose beginner, intermediate, or advanced
2. **Learn a Word** - Click to get a new word with definition and example
3. **Take the Quiz** - Type the word you just learned
4. **Get Feedback** - Instant feedback on whether you're correct
5. **Use Hints** - Stuck? Get a hint about the word
6. **Track Progress** - See your score and learning streak grow!
